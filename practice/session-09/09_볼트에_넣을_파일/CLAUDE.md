# CLAUDE.md — 볼트 작업 규칙

## 폴더
- 00 지도: 학기 지도 · 보고서 질문
- 01 입력: 받은 자료 · 내 메모 (원본, 고치지 않음)
- 02 정리: 근거 노트 · 요약
- 03 출력: 완성한 보고서 · 결과물
- 04 보관: 끝난 것
- 99 첨부: 원문 PDF · 이미지 (자료 노트의 원본)

## 파일
- 파일명: YYMMDD_내용.md
- 맨 위 속성: created · tags · source (자료와 근거 노트는 url · check 추가)
- check 값: 확인 / 부분 확인 / 확인 불가

## 작업 순서
1. 01 입력의 자료 노트를 먼저 읽는다.
2. 보고서 질문마다 자료가 있는지 확인하고, 비어 있는 질문만 웹에서 조사한다.
3. 새로 찾은 근거는 출처 1개 = 근거 노트 1개로 02 정리에 저장한다.
4. 보고서는 03 출력에 저장하고, 문장마다 근거 노트로 [[링크]]를 단다.

## 근거 규칙
- 보고서에는 check가 "확인"인 근거를 쓴다. "부분 확인"은 출처와 확인 수준(예: 보도 기준)을 함께 적는다.
- tags에 "개인메모"가 있는 노트는 참고만 하고 보고서 근거로 쓰지 않는다.
- 조사마다 대상이 다르면 수치를 섞지 않고 조사 이름을 함께 쓴다.

## 지킬 것
- 파일을 지우지 않는다. 옮기거나 새로 만들기 전에 계획을 먼저 보여 준다.
- 새 노트를 만들면 00 지도/학기 지도.md에 링크 1줄을 더한다.
