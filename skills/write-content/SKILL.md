# 기본 글쓰기

1. 먼저 읽는 사람, 글 종류(칼럼·공지·메일·소개글), 분량을 확인한다. 요청에 없는 것은 쓰기 전에 한 번에 하나씩 묻는다.
2. 구조는 제목 1줄 → 핵심 1~3줄 → 세부 → 요청이나 다음 행동 순서로 잡는다. 글 종류별 형식은 references/writing-rules.md의 형식표를 따른다.
3. 숫자, 날짜, 이름은 입력 그대로 쓴다. 입력에 없는 사실은 추가하지 않고, 필요하면 "확인 필요"로 표시한다.
4. 초안을 쓴 뒤 references/writing-rules.md의 점검 6항목으로 스스로 고친다.
5. 결과 첫 줄에 글 종류와 글자 수를, 마지막 줄에 "점검: 6항목 통과" 또는 고치지 못한 항목을 적는다.
6. 게시와 발송은 하지 않고 초안만 보여 준다.
