# 칼럼 규칙

## 1. 문장
- 합니다체로 쓰고, 한 글 안에서 해요체·한다체를 섞지 않는다.
- 한 문장은 공백 포함 60자를 넘기지 않고, 한 문장에는 한 가지 내용만 쓴다.
- 결론을 먼저 쓰고 근거를 뒤에 붙인다.

## 2. 쓰지 않는 표현
- 과장: 압도적인, 최고의, 놀라운, 엄청, 대폭, 혁신적인, 획기적인, 완벽한
- 모호한 부사: 매우, 정말, 너무, 진짜, 완전, 쉽게, 빠르게
- 흐린 끝맺음: "~할 수 있습니다"는 가능·허용을 뜻할 때만 쓴다. "~것 같습니다"는 쓰지 않는다.
- 대신 숫자, 날짜, 사례, 행동으로 쓴다. 예) "많은 학생이 쓴다" → "우리 조 5명 중 4명이 쓴다" (숫자는 입력에 있을 때만 쓴다)

## 3. 칼럼 형식
| 자리 | 쓰는 것 |
|---|---|
| 제목 | 주장 1줄 |
| 도입 | 경험이나 사례 1문단 — 사용자가 말한 경험만 쓴다 |
| 본문 | 근거 → 판단 기준(질문 2~3개 또는 기준 2~3개) |
| 끝 | 정리 1문장 |

## 4. 점검 7항목
1. 읽는 사람이 첫 3줄만 읽어도 주장을 안다.
2. 숫자와 날짜가 입력과 같다.
3. 입력에 없는 사실과 경험이 없다.
4. 쓰지 않는 표현이 0건이다.
5. 공백 포함 60자를 넘는 문장이 없다.
6. 합니다체 하나로 끝까지 썼다.
7. 마지막에 정리 1문장이 있다.
