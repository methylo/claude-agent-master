# 칼럼 쓰기

1. 먼저 읽는 사람, 실을 곳(소식지·학보·블로그), 분량을 확인한다. 요청에 없는 것은 쓰기 전에 한 번에 하나씩 묻는다.
2. 구조는 제목(주장 1줄) → 경험이나 사례 → 근거 → 판단 기준 → 정리 1문장 순서로 잡는다. 세부 규칙은 references/writing-rules.md를 따른다.
3. 숫자, 날짜, 이름은 입력 그대로 쓴다. 입력에 없는 사실과 경험은 추가하지 않고, 필요하면 "확인 필요"로 표시한다.
4. 초안을 쓴 뒤 references/writing-rules.md의 점검 7항목으로 스스로 고친다.
5. 결과 첫 줄에 "칼럼 · 글자 수"를, 마지막 줄에 "점검: 7항목 통과" 또는 고치지 못한 항목을 적는다.
6. 게시는 하지 않고 초안만 보여 준다.
