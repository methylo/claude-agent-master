# 디자인 설정 (theme)

scripts/build_slides.py 는 조판할 때마다 아래 "설정값" 표를 읽는다. 색·글꼴을 바꾸려면 이 표의 값만 고친다. 스크립트는 고치지 않는다.

## 설정값

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| INK | #1F1D1B | 먹색. 제목·본문 글자, 표지 오른쪽 패널, 마무리 장 배경 |
| ACC | #C9654D | 강조색. 장 번호, 요점 키, 표 머리 선, 비교 오른쪽 머리, 흐름 번호 |
| BOX | #F7F2EC | 상자색. 흐름 상자, 표 강조 행, 비교 왼쪽 머리 |
| FONT | 맑은 고딕 | 모든 글자 |

고치는 규칙
- 색은 # 뒤 6자리 16진수로 쓴다. 형식이 틀리면 기본값(위 표의 처음 값)으로 조판한다.
- 이름 칸(INK·ACC·BOX·FONT)은 바꾸지 않는다. 값 칸만 바꾼다.
- 나머지 색(보조 글자·구분선·2단 상자)은 세 색에서 자동 계산한다.
- 글꼴은 발표할 컴퓨터에 설치된 글꼴 이름을 쓴다. 맥에서 맑은 고딕이 없으면 "Apple SD Gothic Neo", 구글 슬라이드에 올릴 때는 "Noto Sans KR"로 바꾼다.

## 판형 · 여백 (고정)

| 항목 | 값 |
|---|---|
| 판형 | 16:9, 13.333 × 7.5in (1920 × 1080px 비율) |
| 좌우 여백 | 0.9in, 본문 폭 11.53in |
| 제목 위치 | 위에서 0.8in |
| 본문 영역 | 위에서 2.05~5.58in, 세로 가운데 정렬 |
| 핵심 문장 띠 | 위에서 5.78in, 높이 0.66in 상자색 |
| 하단 문구·쪽 번호 | 위에서 6.92in |

## 글자 크기 (고정)

| 자리 | 크기 |
|---|---|
| 표지 제목 | 44pt 굵게, 2줄 이내 |
| 본문 장 제목 | 32pt 굵게 |
| 핵심 문장 | 20pt 굵게 |
| 본문(요점·비교) | 17pt |
| 표 칸 | 16pt (6행 이상은 14pt) |
| 흐름 단계 이름 · 설명 | 18pt · 14pt (5칸 이상은 16pt · 13pt) |
| 마무리 제목 | 44pt 굵게 |
| 장 번호 · 제목 줄 · 하단 문구 | 11~12pt |

신규 9종의 글자 크기는 types.md 4절에 있다.

브랜드 표기와 강사 표기는 넣지 않는다. 왼쪽 위 제목 줄과 왼쪽 아래 하단 문구는 기획표 JSON의 meta 에서 받는다.
