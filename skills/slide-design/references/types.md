# 장 유형 15종

scripts/build_slides.py 가 조판하는 장 유형 전체다. 장마다 이 중 하나를 고른다. 기본 6종의 JSON 예시는 plan-table.md 4절, 신규 9종은 이 문서 3절에 있다.

## 1. 유형 목록

| 장 유형 | 쓰는 내용 | 화면 모양 | 항목 상한 | 원문 조건 |
|---|---|---|---|---|
| 표지 | 제목 · 기간 · 발표자 | 왼쪽 제목, 오른쪽 먹색 패널 요점 | 오른쪽 3줄 | — |
| 요점 | 핵심 몇 줄, 항목별 설명 | 키 · 설명 행 | 4행 | — |
| 표 | 항목별 상태 · 담당 · 숫자 | 머리 1행 + 본문 행 | 6행 · 5열 | — |
| 흐름 | 짧은 순서 · 단계 | 가로 상자, 번호 · 이름 · 설명 | 5칸 · 설명 3줄 | 순서가 원문에 있다 |
| 비교 | 전과 후, 두 입장 | 두 열 행, 강조할 쪽 지정 | 4행 | 두 쪽이 원문에 모두 있다 |
| 마무리 | 결정 · 다음 할 일 | 먹색 바탕, 제목 · 핵심 문장 · 항목 | 4줄 | — |
| 구분 | 큰 덩어리의 시작 | 상자색 바탕, 큰 번호 · 덩어리 제목 | 설명 2줄 | — |
| 질문 | 청중에게 던질 질문 하나 | 가운데 큰 질문 · 보조 1줄 | 질문 2줄 | — |
| 인용 | 원문 · 자료의 한 문장 | 큰 따옴표 · 인용문 · 출처 | 인용문 3줄 | 문장이 원문에 그대로 있다 |
| 수치 | 강조할 숫자 | 큰 숫자 · 설명 1줄 | 3개 | 숫자가 원문에 있다 |
| 카드 | 순서 없는 병렬 항목 | 같은 크기 상자 나란히 | 4개 · 설명 3줄 | — |
| 타임라인 | 날짜가 있는 사건 · 일정 | 가로 선 위 날짜 점 | 6개 | 날짜가 원문에 있다 |
| 세로 단계 | 설명이 긴 단계 | 번호 · 이름 · 설명 한 행씩 | 4단계 | 순서가 원문에 있다 |
| 막대 | 숫자 크기 비교 | 가로 막대 · 값 | 5개 | 숫자가 원문에 있다 |
| 사분면 | 두 기준으로 나눈 4경우 | 2×2 칸, 가로 · 세로 축 이름 | 4칸 | 두 기준이 원문에 있다 |

원문 조건을 채우지 못하면 그 유형을 쓰지 않는다. 근거 칸에 "없음"이 나오는 숫자 · 날짜 · 인용은 만들지 않는다.

## 2. 고르는 기준

| 상황 | 고르는 유형 |
|---|---|
| 숫자 1~3개가 메시지 | 수치 |
| 숫자 크기 차이가 메시지 | 막대 |
| 숫자 3개 이상에 담당 · 상태가 붙음 | 표 |
| 순서가 있고 단계 설명이 8자 안팎 | 흐름 |
| 순서가 있고 단계 설명이 한 문장 | 세로 단계 |
| 날짜가 붙은 순서 | 타임라인 |
| 순서 없이 나란한 항목에 설명이 붙음 | 카드 (짧은 키 · 값이면 요점) |
| 두 시점 · 두 입장 | 비교 |
| 두 기준이 교차 | 사분면 |
| 원문 한 문장이 근거 | 인용 |
| 청중이 답을 생각할 질문 | 질문 |
| 8장 안에서 덩어리가 2개 이상 | 구분 (발표 5분 이하에는 쓰지 않는다) |
| 결론 · 다음 할 일 | 마무리 |

같은 유형을 세 장 연속 쓰지 않는다. 구분 · 질문 · 인용은 장 수를 늘리므로 발표 시간 안에서만 쓴다.

## 3. 신규 9종 JSON

공통 칸: "type", "title", "message"(핵심 문장, 띠에 표시), "notes". 구분 · 질문은 핵심 문장 띠가 없다.

```json
{"type": "구분", "title": "덩어리 제목", "message": "설명 1~2줄", "num": "01"}
{"type": "질문", "title": "질문 위 작은 줄", "question": "질문 1~2줄", "message": "보조 1줄"}
{"type": "인용", "title": "제목", "message": "핵심 문장", "quote": "인용문", "source": "출처"}
{"type": "수치", "title": "제목", "message": "핵심 문장", "items": [["42명", "지원자"], ["14명", "면접 참석"]]}
{"type": "카드", "title": "제목", "message": "핵심 문장", "items": [{"name": "카드 이름", "desc": ["설명 1"]}]}
{"type": "타임라인", "title": "제목", "message": "핵심 문장", "items": [["10-28", "사건"]], "highlight_row": 2}
{"type": "세로 단계", "title": "제목", "message": "핵심 문장", "steps": [{"name": "단계명", "desc": ["설명"]}]}
{"type": "막대", "title": "제목", "message": "핵심 문장", "unit": "명", "items": [["항목", 21], ["항목", 12, "12명(29%)"]], "highlight_row": 1}
{"type": "사분면", "title": "제목", "message": "핵심 문장", "x_axis": "가로 기준", "y_axis": "세로 기준",
 "cells": [["왼쪽 위", "설명"], ["오른쪽 위", "설명"], ["왼쪽 아래", "설명"], ["오른쪽 아래", "설명"]], "highlight": 3}
```

- 구분 "num"을 빼면 구분 장 순서대로 01, 02가 붙는다.
- 막대 값은 숫자로 쓴다. 셋째 칸에 표시 문구를 쓰면 그 문구를 값 자리에 보여 준다. "highlight_row"를 빼면 모든 막대가 강조색이다.
- 타임라인 "highlight_row"를 쓰면 그 점만 강조색, 나머지는 회색이다.
- 사분면 "highlight"는 칸 번호(1~4)다.
- 비교 장의 강조 방향은 "emphasis": "right"(기본) · "left" · "none"으로 정한다. 부정적인 쪽을 강조색으로 두지 않는다.
