# 단계별 대화창 화면

SKILL.md 단계 1~4에서 대화창에 보여 줄 화면 형식이다. 응답 첫 줄은 진행 표시줄, 마지막 줄은 다음 단계 신호다. 예시 원문은 칼럼 「설명할 수 없는 코드는 내 과제가 아닙니다」(5문단), 발표 5분이다.

## 단계 1. 결론 · 흐름

형식: 진행 표시줄 → 가정 1줄 → 문단 분류 표 → 한 문장 결론 → 흐름 5칸 → 신호

```
진행: 1 결론·흐름 ● → 2 장 구성 ○ → 3 장별 상세 ○ → 4 조판 ○
```

발표 시간 5분 · 청중 대학생(원문 화자와 같은 집단으로 가정) · 목적 설득

| 문단 | 내용 | 분류 |
|---|---|---|
| 1 | 오류를 AI에 붙여 넣고 확인 없이 제출, 다음 시간 같은 오류에서 막힘 | 장면 |
| 2 | 통과했지만 실력은 그대로, 고치는 법은 남지 않음 | 주장 · 장면 |
| 3 | AI가 대신한 것은 오류를 읽고 좁히고 다시 돌리는 과정 | 주장 |
| 4 | 제출물은 돌아가는지로 확인, 차이는 같은 오류에서 드러남 | 주장 |
| 5 | 기준: AI가 고친 오류의 원인을 내가 설명할 수 있는가 | 주장 · 예시 |

한 문장 결론: AI가 고친 오류의 원인을 내 말로 설명할 수 없다면, 그 코드는 내 과제가 아니다.

발표 흐름: 오류 장면(1) → 남지 않은 실력(2) → AI가 대신한 과정(3) → 제출물의 한계(4~5) → 설명 질문(5)

고칠 곳을 말하거나, "다음"이라고 하면 장 구성으로 넘어간다.

## 단계 2. 장 구성

형식: 진행 표시줄 → 한 문장 결론 → 4열 요약표 → 장 유형 순서 → 점검 1줄 → 신호

```
진행: 1 결론·흐름 ✓ → 2 장 구성 ● → 3 장별 상세 ○ → 4 조판 ○
```

한 문장 결론: AI가 고친 오류의 원인을 내 말로 설명할 수 없다면, 그 코드는 내 과제가 아니다.

| 장 | 제목 | 핵심 문장 | 시간 |
|---|---|---|---|
| 1 | 설명할 수 없는 코드는 내 과제가 아닙니다 | AI를 쓴 뒤 던질 질문 하나 | 0:20 |
| 2 | 통과한 과제, 다시 막힌 오류 | 고친 코드를 확인 없이 내면 같은 오류에서 다시 막힌다 | 0:50 |
| 3 | 통과 뒤 내게 남은 것 | 과제는 통과했지만 오류 앞에서 내 실력은 그대로였다 | 0:50 |
| 4 | AI가 대신한 과정 | 오류를 읽고 줄을 좁히고 다시 돌리는 과정에서 실력이 쌓인다 | 1:00 |
| 5 | 제출물로 실력을 알 수 없는 이유 | 제출물은 돌아가는지만 보여 주고, 실력은 원인 설명에서 갈린다 | 1:20 |
| 6 | AI를 쓴 뒤 던질 질문 | 원인을 내 말로 설명할 수 없다면 그 코드는 내 과제가 아니다 | 0:40 |

장 유형: 표지 · 흐름 · 비교 · 흐름 · 비교 · 마무리

점검 3/3 통과.

고칠 곳을 말하거나, "다음"이라고 하면 장별 상세를 보여 준다.

## 단계 3. 장별 상세

형식: 진행 표시줄 → 장마다 블록 → 점검 1줄 → 신호. 블록 머리는 "N장 · 장 유형 · 시간", 수정한 장은 머리 끝에 "· 수정"을 붙인다. 비교 장은 왼쪽 · 오른쪽 열 이름을 먼저 적고 행을 "항목: 왼쪽 / 오른쪽"으로 쓴다. 흐름 장은 단계에 번호를 붙인다.

```
진행: 1 결론·흐름 ✓ → 2 장 구성 ✓ → 3 장별 상세 ● → 4 조판 ○
```

**3장 · 비교 · 0:50**
- 제목: 통과 뒤 내게 남은 것
- 핵심 문장: 과제는 통과했지만 오류 앞에서 내 실력은 그대로였다
- 본문 항목: 왼쪽 "제출 파일" / 오른쪽 "나"
  - 결과: 과제 통과 / 실력은 과제 전 그대로
  - 코드: 고친 코드가 남음 / 고치는 법은 남지 않음
- 근거: 2문단
- 노트: 동기들에게서도 비슷한 이야기를 듣는다는 점을 말로 덧붙인다.

**4장 · 흐름 · 1:00**
- 제목: AI가 대신한 과정
- 핵심 문장: 오류를 읽고 줄을 좁히고 다시 돌리는 과정에서 실력이 쌓인다
- 본문 항목: ① 오류 메시지 읽기 ② 의심되는 줄 좁히기 ③ 고친 뒤 다시 돌려 보기
- 근거: 3문단
- 노트: 이 단계를 건너뛰면 오류는 사라져도 오류를 읽는 눈은 생기지 않는다.

(1 · 2 · 5 · 6장 블록도 같은 형식으로 모두 보여 준다.)

점검 5/5 통과.

고칠 곳을 말하거나, "승인"하면 조판한다.

## 단계 4. 조판

형식: 진행 표시줄 → 넘침 점검 1줄 → pptx 파일 제공

```
진행: 1 결론·흐름 ✓ → 2 장 구성 ✓ → 3 장별 상세 ✓ → 4 조판 ●
```

넘침 경고 0건.
