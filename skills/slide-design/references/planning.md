# 기획 절차

SKILL.md 단계 1~3의 세부 기준이다. 1~3절은 단계 1(결론·흐름), 4절은 단계 2(장 구성), 5~6절은 단계 3(장별 상세), 7절은 단계 2·3의 점검이다. 단계별 대화창 화면은 stage-screens.md 를 따른다.

## 1. 입력 확인

| 항목 | 없을 때 |
|---|---|
| 원문 | 받기 전에는 진행하지 않는다 |
| 발표 시간 | 원문 다음으로 먼저 묻는다. 답이 없으면 5분으로 두고 기획표 위에 "발표 시간 5분 가정"을 적는다 |
| 청중 | 원문의 화자와 같은 집단으로 두고 기획표 위에 적는다 |
| 발표 목적 | 설명 · 설득 · 보고 중 원문 성격에 맞는 것으로 두고 적는다 |
| 반드시 넣을 내용 · 뺄 내용 | 없으면 원문 전체를 범위로 둔다 |

- 대화와 첨부에서 확인되는 항목은 다시 묻지 않는다.
- 질문은 한 번에 하나만 한다.

## 2. 정본 고정

1. 원문 문단에 번호를 붙인다(1문단, 2문단 …). 표·목록 원문은 줄 번호를 쓴다.
2. 문단 내용을 네 가지로 나눈다.
   - 사실 · 수치 · 인용: 원문에 적힌 그대로만 쓴다
   - 주장 · 해석: 원문 화자의 판단이다. 더 강하게 바꾸지 않는다
   - 장면 · 예시: 원문에 있는 것만 쓴다. 새 사례를 만들지 않는다
   - 확인 필요: 원문만으로 판단할 수 없는 것. 근거 칸에 "없음"
3. 요약할 때 원문의 의미를 바꾸지 않는다. 원문에 없는 문단·주장이 장에 들어가면 그 장은 기획표에서 뺀다.

## 3. 한 문장 결론과 발표 흐름

장별 칸을 채우기 전에 아래 두 가지를 먼저 정한다.

- 한 문장 결론: 발표가 끝났을 때 청중이 기억할 한 문장. 원문의 결론 문장을 우선 쓴다
- 발표 흐름 5칸: 시작 장면 또는 문제 → 핵심 관점 → 판단 기준 또는 해결 과정 → 사례 · 근거 → 마무리 행동

흐름 5칸이 원문 문단 순서와 다르면 원문 순서를 따르고 차이를 기획표 위에 1줄로 적는다.

## 4. 장 수와 시간 배분

| 발표 시간 | 장 수 | 장당 시간 |
|---|---|---|
| 5분 이하 | 5~6장 | 40~60초 |
| 6~10분 | 6~8장 | 1분 안팎 |
| 10분 초과 | 8장 | 1.5~2분. 늘어난 설명은 발표자 노트에 둔다 |

- 표지는 20~30초로 둔다.
- 결론 · 기준을 말하는 장에 가장 긴 시간을 준다.
- 장별 시간의 합이 발표 시간과 같아야 한다.

## 5. 장별 칸 채우기

- 한 장에 핵심 문장 하나만 둔다. 두 메시지가 들어가면 장을 나누거나 하나를 노트로 옮긴다.
- 근거 칸에는 원문 문단 번호를 쓴다(예: "2문단", "3~4문단").
- 같은 장 유형을 세 장 연속 쓰지 않는다.
- 핵심 문장은 판단이 담긴 문장으로 쓴다. 제목은 plan-table.md 기준대로 20자 이내 명사형이다.

발표 역할과 장 유형 대응

| 발표 역할 | 장 유형 |
|---|---|
| 주제 · 결론 제시 | 표지 |
| 큰 덩어리 시작 (8장 안에 덩어리 2개 이상) | 구분 |
| 장면 · 사건 순서, 과정 | 흐름 · 세로 단계, 날짜가 있으면 타임라인 |
| 문제 진단, 남은 것과 남지 않은 것 | 비교 또는 요점 |
| 핵심 관점 · 근거 여러 개 | 요점 · 카드 |
| 원문 한 문장이 근거 | 인용 |
| 수치 강조 · 수치 비교 | 수치 · 막대 · 표 |
| 두 기준으로 나눈 경우 | 사분면 |
| 청중에게 던질 판단 기준 | 질문 |
| 판단 기준 · 다음 행동 | 마무리 |

유형별 원문 조건과 고르는 기준은 types.md 를 따른다.

## 6. 발표자 노트

- 장마다 1~2문장. 화면 문구를 반복하지 않고, 말로 짚을 원문 내용과 다음 장으로 넘어가는 연결만 쓴다.
- 원문에 없는 내용을 노트에도 넣지 않는다.
- 승인 뒤 JSON의 "notes" 칸으로 옮겨 pptx 발표자 노트에 넣는다.

## 7. 단계별 점검

단계 2 · 3의 결과를 보여 주기 전에 해당 항목을 점검하고, 결과를 표 아래 1줄로 적는다. 단계 1은 점검 없이 결론 · 흐름만 보여 준다.

| 점검 항목 | 단계 2 장 구성 | 단계 3 장별 상세 |
|---|---|---|
| 장마다 핵심 문장이 하나다 | 점검 | 점검 |
| 장별 시간 합이 발표 시간과 같다 | 점검 | 점검 |
| 같은 장 유형이 세 장 연속 나오지 않는다 | 점검 | 점검 |
| 원문에 없는 사실 · 수치 · 사례가 없다 (본문 항목 · 노트 포함) | — | 점검 |
| 근거가 "없음"인 장은 핵심 문장 끝에 (근거 없음)을 붙였다 | — | 점검 |

예: 단계 2 "점검 3/3 통과." / 단계 3 "점검 5/5 통과." 또는 "점검 4/5 — 04장 근거 없음, 확인 필요."

## 8. 대화창 화면

단계 1~4의 화면 형식과 예시는 stage-screens.md 에 둔다.
