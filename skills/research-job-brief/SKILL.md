# 주간 취업 브리핑

하는 일: 사용자가 정한 사이트에서 지역과 관심 분야에 맞고 오늘 기준 접수 중인 공고를 찾아, 표 1개와 이번 주 할 일 3개로 정리한다.
하지 않는 일: 공고에 없는 마감일 · 연봉 · 조건을 지어내지 않는다. 사용자가 정하지 않은 사이트로 넘어가지 않는다. 지원서를 대신 쓰지 않는다.

## 입력

| 항목 | 필수 | 비었을 때 |
|---|---|---|
| 사이트 | 필수 | 묻는다 |
| 지역 | 필수 | 묻는다 |
| 관심 분야 · 직무 | 필수 | 묻는다 |
| 경력 | 선택 | 신입 · 인턴 |
| 보유 역량 | 선택 | 부족한 역량 칸을 생략한다 |
| 공고 수 | 선택 | 5건 |
| 끝 안내 | 선택 | "지원 전에 공고에서 마감일과 조건을 직접 확인하세요." |

- 요청문의 값을 먼저 쓴다. 요청문에 없는 항목만 references/my-info.md에서 읽는다.
- 필수 항목이 비어 있으면 하나씩 묻는다.
- 예약 작업으로 실행 중이면 묻지 않는다. 비어 있는 필수 항목을 "확인 필요"로 적고, 공고 찾기는 하지 않는다.

## 단계
1. 입력을 확인하고 오늘 날짜를 적는다.
2. 사용자가 정한 사이트에서 지역과 관심 분야로 공고를 찾는다. references/sources.md에 그 사이트의 읽기 요령이 있으면 따른다.
3. 공고를 한 건씩 상세 페이지에서 확인한다. 아래 중 하나라도 해당하면 표에서 뺀다.
   - 상세 공고 주소를 확보하지 못함
   - "마감" 표시가 있거나 마감일이 오늘보다 앞섬
   - 상세 근무지가 입력한 지역과 다름 (원격은 입력에 있을 때만 인정)
   - 경력 조건이 입력과 맞지 않음
4. 아래 5열 표로 정리한다.
   | 회사 유형 | 직무 | 마감일 | 요구 역량 | 출처 링크 |
   - 회사 이름 대신 회사 유형(대기업 · 중견 · 중소 · 스타트업 · 공공기관 등)을 먼저 쓰고, 이름은 출처 링크에서 확인하게 한다.
   - 마감일이 공고에 없으면 "상시" 또는 "확인 필요"로 쓴다.
5. 보유 역량이 있으면 요구 역량과 대조한다. 공고 3건 이상에 나온 역량 가운데 내가 없는 것을 "부족한 역량"으로 1~3개 적는다. 공고가 5건 미만이면 2건 이상을 기준으로 한다.
6. 이번 주 할 일 3개로 마친다. "무엇을 · 언제까지" 형식으로 쓴다.

## 공고가 적거나 사이트를 읽지 못할 때
- 조건에 맞는 공고가 3건 미만: 찾은 만큼만 쓰고 표 위에 "조건에 맞는 공고 N건"을 적는다. 넓혀 볼 조건 1줄을 제안한다(예: 지역에 원격 추가). 조건을 스스로 넓혀 찾지는 않는다.
- 0건: 표 대신 "이번 주 조건에 맞는 공고 0건"과 넓혀 볼 조건 1줄을 쓴다. 할 일 3개는 준비 중심으로 쓴다.
- 사이트를 읽지 못함: 다른 사이트로 넘어가지 않는다. "○○를 읽지 못했습니다 — 직접 확인: 주소" 1줄을 쓴다.
- 읽은 목록의 마감일이 대부분 오늘보다 앞서면 "사이트 정보가 오래된 사본으로 보입니다" 1줄을 덧붙인다.

## 결과 형식
- 제목: "주간 취업 브리핑 — YYYY-MM-DD"
- 순서: 조건 1줄(사이트 · 지역 · 관심 분야 · 기준일) → 공고 표 → 부족한 역량 → 이번 주 할 일 3개 → 학교 채용 링크(요청문에 있을 때만) → 끝 안내 1줄

## 문체
- 합니다체로 쓴다. 표 안은 짧은 명사형으로 쓴다.
- 한 문장은 60자 이내로 쓴다.

## 금지어
- 과장 표현: 완벽한, 획기적인, 엄청난, 꿈의 직장
- 흐린 끝맺음: "~것 같습니다"

## 왜 이렇게 하는가
- 공고는 매주 바뀌지만 확인할 항목은 같다. 형식이 고정되어 있어야 지난주 브리핑과 비교한다.
- 사이트 · 지역 · 관심 분야는 사람마다 다르다. 스킬에 박아 두지 않고 요청문에서 받아야 학생마다 그대로 쓴다.
- 채용 사이트 목록에는 등록일이 거의 보이지 않는다. 그래서 "최근 등록"이 아니라 "오늘 접수 중"을 기준으로 하고, 상세 페이지에서 마감 여부를 확인한다.
- 마감일과 조건은 지원 여부를 정하는 정보다. 지어낸 값이 들어가면 지원 일정이 틀어지므로 출처 링크를 반드시 붙인다.
